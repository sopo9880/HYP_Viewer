# HYP Viewer v0.1.5 설치 후 실사용 검증

**이전 버전에서 JSON 서재 백업을 먼저 만들고, 앱을 지우지 않은 채 업데이트해.**
실제 사이트 접근·Android 키·삼성 보안 설정은 자동 테스트만으로 검증할 수 없어.

## 1. 온라인 작품을 오프라인 CBZ로 저장
- [ ] 온라인 열람 가능한 작품의 `⋮ → 온라인 작품 오프라인 저장` 메뉴 선택
- [ ] 작품 이미지 개수와 저장 권한 확인 단계가 정확히 표시되는지 확인
- [ ] 동의하지 않고는 다운로드가 시작되지 않는지 확인
- [ ] 동의 후 다운로드 화면에 총 페이지/진행도/MB가 표시되는지 확인
- [ ] 일시정지는 현재 페이지 완료 후 적용되고, 재개하면 다음 페이지부터 이어지는지 확인
- [ ] 취소하면 기존 CBZ가 삭제되거나 교체되지 않는지 확인
- [ ] 다운로드 완료 후 인터넷 연결 없이 작품 카드를 눌렀을 때 오프라인으로 열리는지 확인
- [ ] 오프라인 파일 삭제 시 서재·즐겨찾기·진행도가 그대로인지 확인

## 2. 자동 표지 / 편집
- [ ] 설정의 `새 작품의 첫 페이지를 자동 표지로 사용`을 끔
- [ ] 새 작품을 추가해 기본 디자인 표지로 시작하는지 확인
- [ ] 설정을 켜고 새 작품을 추가해 첫 페이지 표지 준비가 되는지 확인
- [ ] 설정 → 표지 편집 → 원하는 서재 작품 검색
- [ ] 기본 디자인 6종 중 선택
- [ ] 내 이미지 업로드 후 드래그·손가락 확대·축소·잘라 저장
- [ ] 작품 내 원하는 페이지를 불러와 같은 방식으로 표지 자르기
- [ ] 이미지 뷰어 상단 '표지로 지정'에서 현재 페이지 자르기
- [ ] 앱을 재시작해 사용자가 고른 썸네일이 유지되는지 확인

## 3. Android 장치
- [ ] 설정의 볼륨키 페이지 이동을 켠 상태에서 볼륨+ 이전 / 볼륨− 다음 확인
- [ ] 뷰어에서 나가면 볼륨키가 시스템 음량 조절로 복원되는지 확인
- [ ] 2쪽 모아보기에서 기기를 눕히면 가로 회전이 가능한지 확인
- [ ] '2쪽 보기에서 가로 화면 고정'을 켜면 뷰어에서만 가로 고정되는지 확인
- [ ] 뷰어를 닫으면 기기 화면 회전 설정이 정상 복원되는지 확인
- [ ] Android 최초 실행 시 설치 보안 안내가 나오는지 확인
- [ ] 보안 설정 확인 버튼을 **사용자가 직접** 눌렀을 때 기기 설정이 열리는지 확인
- [ ] 앱이 보안 기능을 자동으로 꺼버리지 않는지 확인

## 4. 관리자 공지
- [ ] 기본값이 수신 거부(OFF)인지 확인
- [ ] 설정 → 공지 목록 확인 버튼으로 공지를 볼 수 있는지 확인
- [ ] 공지 수신을 켜고 앱을 재실행하면 새 공지를 표시하는지 확인
- [ ] GitHub Actions에 권한 있는 관리자가 공지를 게시할 수 있는지 확인
- [ ] 수신 거부 시 자동 공지 확인을 하지 않는지 확인
- [ ] 앱 종료 상태 원격 푸시는 아직 지원하지 않는다는 설명 확인

## 오류 보고
Windows/Android, 앱 버전, 작품 번호, 페이지, 정확한 오류 문구,
볼륨키/회전 상태, DNS 여부, 현재 화면을 알려줘. 개인 비밀은 보내지 마.
