# HYP Viewer v0.1.8 — 설치 후 검증

1. 홈의 Shorts 입력창에 숫자만 입력하고 **작품 찾기**. YouTube 댓글 요청 없이 작품을 서재에 등록하고 **내 서재** 화면으로 이동하는지 확인합니다.
2. 새 설정 **서재 추가 후 작품 자동 열기**는 기본 **꺼짐**. 켜면 한 작품 저장 뒤 앱 내 뷰어를 열며 여러 작품을 함께 저장할 때는 내 서재로 이동합니다. 온라인 접근 제한 시 오류 알림이 표시될 수 있습니다.
3. 긴 홈 화면 중간이나 맨 아래로 스크롤한 상태에서도 알림이 **현재 화면 상단**에 표시되며 X 버튼으로 닫히는지 확인합니다.
4. Android 휴대폰의 좁은 화면에서 쇼츠 댓글 조회 후 후보가 있으면 **#번호 칩**이 검색창 아래에 나타나는지 확인합니다. 칩을 누르면 번호 입력란으로 이어집니다. YouTube가 댓글을 차단하면 복사·붙여넣기 방식으로도 후보를 생성할 수 있어야 합니다.
5. **설정 → 언어**를 한국어, English, 日本語로 바꾸면 메뉴·버튼·주요 설명이 즉시 바뀌고 앱 재실행 후에도 유지되는지 확인합니다. 원본 작품명과 외부 API의 원문은 번역하지 않습니다.
6. **설정 → 업데이트**에 설치된 버전 **v0.1.8 (build 9)** 가 표시되는지 확인합니다.
7. 기존 v0.1.7 설치 위에 Windows/Android 업데이트하여 서재 JSON·로컬 CBZ·표지·즐겨찾기가 그대로 유지되는지 확인합니다.

## 유의 사항
- YouTube 공개 댓글은 플랫폼 접근 제한에 따라 빈 목록이거나 실패할 수 있습니다. 빈 목록에서는 존재하지 않는 후보 번호를 만들어내지 않습니다.
- Android One UI 보안 설정은 기기/버전에 따라 다를 수 있습니다.
- 언어 설정은 앱 인터페이스를 대상으로 하며 사용자 작품명, 검색 결과의 서버 메타데이터, 외부 링크 내용은 자동 번역하지 않습니다.
