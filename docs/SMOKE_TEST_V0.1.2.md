# HYP Viewer v0.1.2 실제 업데이트 검증

검증 목적: v0.1.1 Windows 리더에서 작품을 클릭하면 `1 / 32` 페이지 표시만
나오고 **이미지는 검은 화면**으로 남던 문제의 개선 여부 확인.

## 설치 전

- v0.1.1의 서재를 JSON으로 백업해.
- 기존 앱을 삭제하지 말고 정식 서명된 v0.1.2 APK / v0.1.2 Windows
  Setup.exe를 설치해. Android의 build number는 2 -> 3이야.
- 라이브러리와 읽기 기록이 그대로 있는지 확인해.

## 핵심 재현 검사 (Windows 우선)

1. v0.1.1에서 검게 보였던 **같은 작품**을 서재에서 클릭해.
2. `1 / 32`처럼 페이지 수가 인식되는지 확인해.
3. **하단 페이지 슬라이더가 화면 맨 아래에 있는지** 확인해. 이전처럼
   화면 중앙에 나타나면서 페이지를 가리지 않아야 해.
4. **실제 첫 페이지 이미지가 로딩되는지** 확인해. 첫 페이지가 보이면
   2~3페이지로 넘기고 이전 페이지로 돌아와 봐.
5. 여전히 실패한다면 이번 버전에서는 검정 화면 대신 **오류 내용**,
   **다시 시도**, **웹 리더로 열기** 버튼이 보여야 해.
6. **다시 시도**를 누르고, 이어서 **웹 리더로 열기**가 작품 번호 및
   페이지별 고정 형식(`#1-`, `#2-3`)으로 동작하는지 확인해.
7. 로그나 스크린샷을 보내줄 때 오류 문구와 작품 번호(가능하면)를
   알려줘. 계정 비밀번호, YouTube API 키, 쿠키 등은 보내지 마.

## 다른 기능 회귀

- [ ] 앱 내 페이지 이동 및 마지막 페이지 저장
- [ ] CBZ/ZIP 오프라인 이미지 읽기
- [ ] 서재와 즐겨찾기 보존
- [ ] API 키 없이 공개 Shorts 댓글 자동 수집
- [ ] JSON 백업/복원 및 Excel 내보내기
- [ ] 정식 v0.1.2 업데이트 확인

**중요:** Flutter 모의 HTTP 테스트와 Windows/Android 빌드가 통과해도
실제 사이트에서 이미지가 나온다는 보장은 아니야. 접근 제한, 사이트
구조 변경, 또는 이미지 디코딩 실패는 이 설치 테스트를 통해 확인해.
그 결과를 바탕으로 다음 0.x 업데이트를 개발해.
