# HYP Viewer v0.1.4 실사용 검증

기존 앱의 **설정 → JSON 백업**을 먼저 실행해. 기존 앱을 제거하지 말고 Windows
Setup.exe 또는 같은 키로 서명한 Android APK를 **덮어 설치**해.

## 1. 이미지 서버 진단

- [ ] v0.1.2에서 실패했던 작품 번호로 읽기 시작
- [ ] 이미지가 나오면 1~5페이지와 앞/뒤 이동을 반복
- [ ] 실패하면 메시지에 **WebP 호스트(w1/w2)**, DNS 또는 HTTP 오류
  원인이 구분돼 표시되는지 확인
- [ ] **다시 시도**, **웹 리더로 열기**가 눌리는지 확인

> v0.1.3에서 숫자형 1./2. 호스트 JPG fallback을 제거했어.
> 여전히 DNS 장애가 나오면 소스 웹사이트 접속 상태·네트워크 제한 문제일 수
> 있으며 이 테스트 전에 정상 동작을 보장하지 않아.

## 2. 서재 저장 오류 재현

- [ ] 기존 서재/진행도/즐겨찾기가 업데이트 후 그대로인지 확인
- [ ] 읽는 도중 앞으로 10페이지, 뒤로 10페이지 빠르게 이동
- [ ] 화면을 닫고 다시 열어 마지막 읽은 페이지가 유지되는지 확인
- [ ] 파일 사용 중 (errno 32) 저장 실패 메시지가 재현되는지 확인
- [ ] 작품 즐겨찾기와 표지 변경을 연이어 수행해 기록이 덮어써지지 않는지 확인

## 3. 사용자 설정과 키보드 조작

- [ ] 설정 → 뷰어 방향: 왼쪽 넘기기와 오른쪽 넘기기 변경
- [ ] 이전 페이지 / 다음 페이지 버튼이 모두 작동
- [ ] 물리 키보드: ←/→ (방향 반영), PageUp/PageDown, Space, Home/End
- [ ] 물리 키보드: Esc로 닫기
- [ ] 서재 단축키: Ctrl+1 홈, Ctrl+2 서재, Ctrl+3 즐겨찾기,
  Ctrl+4 다운로드, Ctrl+5 설정, Ctrl+F 서재 검색
- [ ] 2쪽 모아보기: 1-2 → 3-4 → 5-6 순서로 이동
- [ ] 미리 로딩(0~3장)을 변경한 뒤 앞뒤로 이동할 때 이미 로드된 페이지의
  재요청이 줄어드는지 확인

## 4. 썸네일

- [ ] 저장된 작품의 자동 첫 페이지 썸네일이 준비되는지 확인
- [ ] 작품 카드 메뉴 → 표지 선택 → 내장 6종 중 한 가지 선택
- [ ] 작품 카드 메뉴 → 표지 선택 → 작품 내 특정 페이지 선택
- [ ] 뷰어 상단 '현재 페이지를 서재 표지로 지정' 실행
- [ ] 앱을 다시 실행해 표지 선택이 유지되는지 확인
- [ ] JSON 백업/복원 시 선택한 기본 표지/페이지 번호가 보존되는지 확인

> 썸네일 이미지 자체는 로컬 캐시이며 JSON 백업에 포함되지 않아.
> 다른 PC로 백업을 복원하면 이미지 미리보기가 다시 생성될 수 있어.

## 오류 보고에 포함할 내용

OS, HYP 버전, 작품 번호, 현재 페이지, 설정한 넘김 방향/양면 설정,
버튼 또는 단축키, 정확한 오류 메시지와 화면을 알려줘.
API 키, 로그인 쿠키, 개인 경로의 민감한 정보는 보내지 마.

문제가 있으면 v0.1.5 등 **다음 0.x 릴리스**에서 수정해.
