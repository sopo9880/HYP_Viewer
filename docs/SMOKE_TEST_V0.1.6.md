# HYP Viewer v0.1.6 기능 테스트 (정식 릴리스 전)

이번 PR은 기능만 개발하며 `pubspec.yaml` 버전 및 기존 v0.1.5 Release 파일을 변경하지 않습니다.
정식 설치 파일은 릴리스 요청을 따로 검증/병합한 후에만 생성합니다.

## 1. 하나의 쇼츠에서 작품 2개 저장

1. `https://youtube.com/shorts/cY9STsWLA-Y`를 붙여넣고 작품 찾기
2. 댓글 조회가 막히면 실제 1편/2편 코드를 댓글 입력창에 직접 붙여넣어 추출
3. 후보 2개가 별개의 번호로 표시되는지 확인
4. 두 후보가 체크되어 있을 때 **선택한 작품 2개 한 번에 저장**
5. 내 서재와 JSON 백업에 서로 다른 작품 2개가 남는지 확인
6. 둘 중 하나만 즐겨찾기/읽기 기록을 바꾸고 다른 항목이 바뀌지 않는지 확인

동일한 쇼츠의 **서로 다른 작품 번호**는 독립된 항목입니다.
숫자 후보가 3개 이상이면 잘못된 숫자를 저장하지 않도록 수동으로 체크합니다.

## 2. 홈 일러스트

설정 → 홈 배너 일러스트 → PNG/JPG/WebP 업로드 (최대 12 MB).
홈 소개 첫 번째 슬라이드의 텍스트/버튼이 배경 사진 위에서 읽히는지 확인합니다.
앱 재실행 후 보존 여부와 기본 배경 복원을 확인합니다.
이미지 파일은 기기 로컬에만 저장되며 JSON 백업에 포함되지 않습니다.

## 3. 자동 제목

작품 번호만 입력하고 제목을 비운 채 저장합니다.
메타데이터 서버 응답이 성공하면 작품 제목이 자동 입력되고,
접속할 수 없으면 `작품 {번호}`로 안전하게 저장됩니다.
이후 온라인 읽기에 성공하면 임시 제목을 실제 제목으로 갱신합니다.
쇼츠 동영상의 제목을 여러 작품의 작품명으로 잘못 재사용하지 않아야 합니다.

## 4. RTL 하단 바

설정에서 `오른쪽으로 넘기기`를 선택하고 뷰어를 엽니다.
다음 버튼은 왼쪽, 이전 버튼은 오른쪽에 나타나고,
슬라이더의 첫 페이지 위치가 오른쪽에 있어야 합니다.
다른 방향으로 전환하면 두 동작 모두 원래대로 돌아가야 합니다.

## 5. 가로/세로 전환 설정

뷰어 우측 상단 가로/세로 전환 아이콘을 누르면 즉시 전환됩니다.
설정 → 이미지 뷰어 설정 → `세로로 페이지 넘기기`에서도 동일 항목을 변경할 수 있습니다.
앱 재실행 후 선택이 유지되는지 확인합니다.
2쪽 모아보기는 별도의 가로 배치 옵션을 사용합니다.

## 6. Android 업데이트 흐름

1. 서명된 이전 버전에서 새 v0.x 릴리스를 다운로드하고 SHA-256을 검증
2. APK 설치를 시작하기 **전에** Android 보안 설정 화면이 열리는지 확인
3. 기기의 보안 위험 자동 차단/알 수 없는 앱 허용 여부를 사용자가 **직접** 확인
4. 뒤로 가서 HYP Viewer로 돌아오면 설치 확인 다이얼로그가 뜨는지 확인
5. **설치 화면 열기**를 누르면 Android 시스템의 실제 APK 설치 승인 화면으로 이동하는지 확인
6. 설치를 취소해도 기존 앱/서재가 지워지지 않는지 확인

앱이 보안 위험 자동 차단 기능을 자동으로 끄거나 설정을 조작하지 않습니다.
Samsung One UI 버전에 따라 보안 설정 메뉴 위치가 다를 수 있습니다.

## 검증 범위

자동 Flutter 단위/위젯 테스트 및 GitHub Actions Windows/Android 빌드를 통과해야 합니다.
제공된 YouTube Shorts 댓글의 **실시간 내용**은 API 제한으로 확인되지 않을 수 있으며,
실기기 설치 화면/브라우저 동작은 릴리스 후 별도 실사용 검증이 필요합니다.
