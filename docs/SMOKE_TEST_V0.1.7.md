# HYP Viewer v0.1.7: 서재 삭제 기능 검증

## 확인할 동작
1. 내 서재 → 작품 카드 오른쪽 아래 **⋮** → **서재에서 작품 삭제**를 선택합니다.
2. 취소를 누르면 작품·즐겨찾기·읽기 기록·로컬 CBZ/표지가 그대로 유지되어야 합니다.
3. 로컬 파일 체크박스를 끈 채 삭제하면 해당 작품의 서재 항목/즐겨찾기/열람 기록만 사라집니다. 다른 작품은 유지되어야 합니다.
4. 앱을 재실행한 뒤에도 서재에서 사라졌는지, JSON 내보내기에 삭제된 항목이 없는지 확인합니다.
5. 이 상태에서 동일 번호를 재등록하면 남겨둔 오프라인 파일을 다시 인식해야 합니다.
6. 재등록 후 다시 삭제할 때 **로컬 파일도 함께 삭제**에 체크하면 CBZ와 로컬 표지 미리보기가 제거되어야 합니다.
7. **오프라인 파일 삭제** 메뉴는 예전처럼 서재 항목을 그대로 두고 CBZ만 지웁니다.
8. 다운로드가 진행 중인 작품은 완료/취소 전 서재 삭제를 막아야 합니다.
9. 같은 쇼츠에서 저장한 2개 작품 중 하나만 지웠을 때 다른 작품의 즐겨찾기·진행도는 유지되어야 합니다.

## 주의 사항
- 서재에서 삭제하면 메타데이터/읽기 기록/즐겨찾기가 사라집니다. 삭제 전 JSON 백업을 권장합니다.
- 체크하지 않은 로컬 파일은 기기에 남습니다. 서재에 작품을 다시 추가하면 다시 연결할 수 있습니다.
- 이미 별도로 내보낸 오래된 JSON 백업을 다시 가져오면 삭제했던 작품이 복원될 수 있습니다.
- 로컬 파일 삭제에 실패하면 서재 항목 삭제는 완료되고 오류 메시지로 일부 정리가 실패했음을 알려줍니다.
